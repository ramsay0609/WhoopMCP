# Privacy Policy — WhoopMCP

**Last updated: October 18, 2026**

WhoopMCP is a personal-use tool built and used solely by its developer to access the developer's own WHOOP data for personal fitness tracking and analysis. It is not offered, marketed, or made available to any other users.

## Data accessed

Via the WHOOP API and with the developer's explicit OAuth consent, the app reads the developer's own profile, body measurements, cycles, recovery, sleep, and workout data.

The app also stores data the developer enters themselves: goals, and life events such as alcohol, travel or illness logged for personal analysis.

## Data storage and sharing

- All data is stored locally on the developer's own devices, in a local database and token file readable only by the developer's user account.
- No data is stored on external servers operated by this app.
- When the developer asks their AI assistant a question, the data returned by the app's tools is sent to that assistant's provider (for example Anthropic, for Claude) as part of the conversation, under that provider's terms. This happens only at the developer's own request.
- No data is sold to, or otherwise shared with or disclosed to, any other third party.
- No other users have access to this application or its data.

## Deletion

The developer can delete all stored data at any time by removing the local data folder (`~/.whoop-mcp/`), and can revoke the app's access from their WHOOP account.
